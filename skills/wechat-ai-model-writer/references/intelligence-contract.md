# AI 模型省钱情报 → 公众号输入契约

这个文件规定原始情报进入公众号编辑阶段前，应该如何整理事实。它不是文章模板。

## 每条情报建议字段

```text
model_vendor        厂商
model_name          模型完整名称 / 版本
region              中国 / 海外 / 全球
happened             发布 / 升级 / 降价 / 免费额度 / 渠道变化 / 限速变化
happened_at          事件日期
verified_at          价格与渠道核验日期
strengths            编程 / 推理 / 长文本 / 图像 / Agent / 搜索 / 日常问答
official_channel     官方网页 / 官方 API / 官方 App
other_channels       云平台 / 聚合平台 / 中转站
input_price          输入价格
output_price         输出价格
price_unit           原始计价单位，优先记录每 1M tokens
currency             币种
cached_price          缓存价（如有）
batch_price           Batch / 异步价（如有）
free_tier             永久免费层（如有）
trial_credit          新用户 / 一次性免费额度（如有）
subscription_price    包月 / 套餐（如有）
context_window        上下文长度
rate_limits           速率 / 并发 / 每日限制（如影响使用）
promo_expires_at      优惠结束时间（如有）
channel_risk          official / cloud / aggregator / unofficial_proxy
primary_sources       官方公告 / 定价页 / 文档
secondary_sources     权威媒体 / 第三方说明
notes                 其他限制
```

字段缺失时可以为空，但不得猜测填充。

## 价格归一化

为了让公众号表格可比较，优先把 API 标准按量价整理为：

```text
输入：X / 1M tokens
输出：Y / 1M tokens
```

同时必须保留：

- 原币种；
- 是否含税（来源明确时）；
- 是否是标准价、缓存价、Batch 价或活动价；
- 核验日期。

### 不允许混为一谈

以下价格不是同一概念：

```text
标准按量价
缓存命中价
Batch / 异步价
长上下文阶梯价
包月套餐摊销价
新用户赠送额度折算价
限时促销价
```

表格需要比较时，应优先比较相同计费模式；否则在列名或注释中明确差异。

## 免费的分类

必须区分：

### 永久免费层

官方长期存在、规则公开的 free tier。

### 新用户额度

注册或首次开通后一次性赠送的 credit / token / 金额。

### 限时免费

活动期免费、Beta 免费、短期试用等。

### 产品免费使用

Chat / App 可以免费使用，但不代表 API 免费。

公众号里不要只写“免费”，要写清是哪一种。

## 渠道分类

### `[官方]`

模型厂商自己的 App、网页、API 或开发者平台。

### `[云平台官方接入]`

例如主流云平台与厂商正式合作提供的模型服务。价格、版本和地域可能与模型厂商官方 API 不同。

### `[正规聚合平台]`

平台主体、定价、隐私政策和模型路由相对明确，但仍要说明其不是模型原厂。

### `[非官方中转]`

没有明确原厂授权或通过转发账户 / Key 提供模型能力的服务。

这类渠道即使便宜，也必须把风险和价格一起呈现。不要写成无条件推荐。

## “今天最省钱”的判断维度

不能只看 token 单价。至少考虑：

```text
任务能力是否够用
+ 标准价格
+ 免费额度
+ 上下文
+ 限速 / 并发
+ 调用稳定性
+ 渠道可信度
+ 迁移与兼容成本
```

因此推荐语应尽量写成：

```text
“在批量文本推理场景里，目前更划算”
```

而不是：

```text
“这是全网最便宜的模型”
```

除非比较范围足以支持绝对结论。

## 来源优先级

```text
官方发布 / 官方定价 / 官方文档
> 云平台官方产品页
> 权威媒体
> 正规第三方平台文档
> 社区帖子 / 社交媒体二手转述
```

重大价格结论最好至少能回到官方定价页或官方文档。
