# 光愈在线首篇上线文章：图片化格式研究

> 研究对象：用户提供 `光愈在线公众号.zip` 中的《2026年马踏新途，势启未来！光愈在线全新上线，与您共同迎新！》HTML。
>
> 该文发布时间为 **2026-02-13 20:00**；在当前 ZIP 的 11 篇文章中，它是最早的一篇，因此可作为“首篇上线/品牌启动文章”的参考样本。这里不据此断言它一定是账号历史上绝对第一篇，只记录当前样本集事实。
>
> 原始 HTML、图片、二维码和品牌资产不提交仓库。

## 1. 这篇并不是“整篇只有图片”

HTML 检查结果：

```text
#js_content 可见正文文本约 274 字
img 标签                 15 个
大幅内容图               5 张
其余                     关注条小图标 / 装饰图标 / 二维码等
```

所以它属于：

> **图片主导的品牌上线文章 + 少量富文本说明**

不是“一张超长图”，也不是纯文字文章。

正文中真实存在的文字包括：

```text
点击蓝字 关注我们
马踏新途，势启未来……
光愈在线全新上线，新年与您共同迎新！
“光愈在线”小程序是一款……
内容中心
直播中心
个人中心
免责声明
```

因此复用时应借鉴“图片承担主要视觉叙事、文字承担过渡和解释”的方式，而不是简单把整篇文章 rasterize 成一张图。

## 2. 封面尺寸

HTML 的 `og:image / msg_cdn_url` 对应本地保存封面：

```text
格式         JPEG
原始尺寸     1280 × 544 px
宽高比       2.35294 : 1
```

这几乎就是标准 **2.35:1** 公众号封面。

视觉特征：

```text
大面积暖红 / 珊瑚红 / 粉红渐变
高饱和红色主标题
白色/浅粉主体形象
大标题优先，品牌 Logo 较小
背景有点阵、速度线、波纹等动势元素
```

从本地封面像素提取的主要颜色近似：


注意：这些颜色是该首篇新年上线 KV 的样本色，不等于以后所有文章都必须使用完全相同的色板。

## 3. 正文主 KV / Hero

首个真正的大幅正文视觉：

```text
格式         PNG
原始尺寸     1080 × 1920 px
宽高比       9 : 16
HTML 显示宽  约 677 px / max-width 100%
```

这是典型的**竖版海报式主 KV**，承担了首屏品牌发布感：

```text

“全新上线 / 共同迎新”副标题
```

这张图说明：首篇品牌文章可以在封面之后，再用一张高完成度 9:16 竖版主 KV 建立品牌气质。

## 4. 正文大图尺寸谱

除 9:16 Hero 外，HTML 中还有 4 张全宽核心内容图：

| 角色 | 格式 | 原始尺寸 | 约宽高比 | HTML 逻辑 |
|---|---|---:|---:|---|
| 横向总览 / 过渡视觉 | PNG | 1008 × 489 | 2.06:1 | 全宽显示 |
| 内容中心展示 | PNG | 1080 × 1161 | 0.93:1 | 接近方形偏竖 |
| 直播中心展示 | PNG | 1080 × 731 | 1.48:1 | 横向信息板 |
| 个人中心展示 | PNG | 1080 × 483 | 2.24:1 | 宽横条信息板 |

共同规律：

```text
设计源文件宽度大多约 1080px
↓
发布到公众号时统一缩放到正文宽度约 677px
↓
max-width: 100%
height: auto
line-height: 0 的图片容器
```

这是一条很值得复用的制作经验：

> **图片先按高分辨率 1080px 级宽度设计，再交给微信按正文宽度缩放，而不是直接按手机显示宽度设计。**

## 5. PNG 与 JPEG 的使用习惯

该首篇样本中：

### PNG

用于：

```text
主 KV
功能模块图
带大量文字的设计稿
UI / 信息板
透明小图标
```

原因：文字边缘、线条、图标和大面积纯色更适合无损 PNG。

### JPEG

明确出现于：

```text
公众号封面 1280×544
底部 776×776 方形图（在 HTML 中以约 110px 圆形区域展示）
```

对于 `医荟她健康` 后续制作：

- 封面允许 JPEG，高质量输出即可；
- 正文内含文字、图表、UI、品牌 KV 的图优先 PNG；
- 不为追求小文件而把小字号中文图表强行转 JPEG，避免压缩糊字。

核心不是“每段都做图片”，而是：

> **用 4~5 张高完成度大图承担品牌故事主线，富文本只做必要的连接。**

## 8. 当前没有小程序时的首篇替代结构

`医荟她健康` 当前没有小程序，因此如果以后制作首篇品牌上线文章，不应照搬原文的“小程序三中心”。更合适的图片化结构是：

```text
封面 2.35:1
↓
9:16 品牌 Hero：医荟她健康正式启程 / 品牌主张
↓
我们是谁：女性健康医学内容平台/公众号定位
↓
我们关注什么：宫颈健康 / HPV / 妇科 / 女性全生命周期健康等
↓
你会在这里看到什么：科普、指南/共识解读、研究解读、专家内容等
↓
为什么值得关注：可信、循证、清晰、可行动
↓
未来规划：如用户明确需要，可谨慎写“后续考虑更多服务形态”，但不把小程序写成已上线
↓
公众号关注二维码 / 真实品牌素材（用户提供后）
↓
免责声明
```

这里是**格式迁移建议**，不是固定文章模板；具体文字与结构仍由当次 Writer 根据目标和受众决定。

## 9. 图片 QA

制作类似首篇品牌文章时检查：

```text
[ ] 封面是否约 2.35:1，缩略图标题仍清楚？
[ ] 主 KV 是否有一张 9:16 或等效高冲击竖版图？
[ ] 正文设计源图是否优先使用 1080px 级宽度？
[ ] 含小字/图表/UI 的图是否优先 PNG？
[ ] 大图之间是否有短文本过渡，而不是连续堆图无解释？
[ ] 是否把参考品牌资产替换为“医荟她健康”的真实资产？
[ ] 当前无小程序时，是否完全去掉小程序入口/截图/二维码/功能承诺？
```
