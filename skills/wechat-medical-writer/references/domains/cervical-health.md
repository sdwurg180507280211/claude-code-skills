# Domain Reference: Cervical Health

## 角色

这个文件只记录当前医学服务号的**内容方向索引**。

真正写文章时，应读取用户实际提供的 ZIP / PPT / PDF / 论文 / 指南等参考资料；这里的 topic map 不能代替原始资料，也不能单独作为具体医学结论的证据。

## PDT / HAL-PDT 相关参考方向

当前用户资料包涉及的主题范围包括：

- 光动力治疗的发展与基础机制
- 光敏剂、激发光、氧/活性氧等要素
- ALA/HAL 等局部光敏剂相关内容
- 宫颈上皮病变相关机制与组织学资料
- CIN2/HSIL 临床研究
- 疗效、安全性、HPV 等研究终点
- 治疗流程与产品医学教育
- 生育需求患者的相关讨论
- 指南 / 共识 / 注册或说明书相关材料

以上仅表示“参考资料里有这些方向”，不代表这里已经给出任何具体医学结论。

## 使用方式

- 用户要求“参考上传资料写”时：读取实际附件，并以附件支持的内容为准。
- 用户要求“结合最新资料”时：由所选写作/研究 Skill 按它自己的研究流程补充外部来源。
- 不用本文件自行生成固定文章大纲、固定选题结构或固定表达风格。
- 不把原始 ZIP/PPT/PDF 提交到仓库。
